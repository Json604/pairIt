PairIt - AudioRelay — Linux preview

Requirements: Ubuntu 24.04+ or Debian 12+ (x64/ARM64), a graphical X11 session
or Wayland with XWayland, and PulseAudio or PipeWire's PulseAudio compatibility
service. Other glibc distributions may work but are not yet verified.

Recommended Ubuntu/Debian installation
--------------------------------------
Download the .deb matching your computer (amd64 for Intel/AMD, arm64 for ARM).
Open it with your system's graphical package installer and choose Install.
The package manager installs the required libraries, PulseAudio client tools,
and a PairIt application-menu entry. Open PairIt from the application menu.
If your desktop has no graphical .deb installer, one command installs the
local package and dependencies: sudo apt install ./PairIt-*.deb
No .NET installation is required. Installation never starts audio or changes
pairing data. Updating means installing the newer .deb after quitting PairIt.

Portable archive / other distributions
--------------------------------------
The .tar.gz remains available for other compatible glibc distributions.
These need X11 or XWayland, fontconfig, ICU, OpenSSL 3 and PulseAudio client
utilities (pactl, parec, pacat), plus a running PulseAudio or pipewire-pulse
user service. Package names vary by distro; this archive does not install them.
On Ubuntu/Debian the .deb above is the simpler route.

Extract the entire archive. Run ./PairIt as your normal desktop user, never root.
Choose the output your apps use in Settings, then select Pair a phone. On the
same local network, scan the QR code or paste the pairing code into PairIt on
your phone. Sharing captures audio only when a phone requests it.
If you have several network addresses, choose the one reachable by the phone.
A valid QR code connects from the phone. The computer shows live listening or paused status.
Allow incoming TCP 5002 from your trusted local network if a firewall blocks it.
Do not forward that port through your router.
Nearby discovery uses multicast UDP 5353 on the local network. If blocked,
QR pairing still works. Discovery never broadcasts the private pairing token.

The Phone / Computer switch preserves live phone connections.
Phone playback temporarily routes applications using the selected output to a
private PairIt output, so they do not also play through the laptop speakers.
Other outputs are left alone. Computer restores local playback. Pausing an
already listening phone keeps its private route; disconnecting the last phone
or closing PairIt restores the output. Manual routing choices made in system
audio settings are preserved. Physical speaker mute settings are not changed.
Paused phones stay paused. There is no automatic player pause
or Mac-style video compensation in this Linux preview. Capture timing is
approximate; hardware listening validation is still needed.

Closing the window stops sharing. Pairing is saved privately under
$XDG_DATA_HOME/PairIt (normally ~/.local/share/PairIt). Do not delete identity.json
to fix a startup problem: existing phones trust that identity. The directory
must have mode 700, and identity.json mode 600. Never share those files or codes.

PairIt checks for updates at startup and on foreground (at most once per six hours).
An available update appears in the main window. Settings → Check for updates
checks immediately. Download opens the official release page; it does not install
or run anything automatically. Quit PairIt, then install the newer .deb or replace
the extracted portable app.
Replace the extracted app files after closing PairIt; keep your user data.

Optional application-menu entry: run ./install-desktop.sh from the extracted
folder. It points at this folder, so keep the folder in a permanent location.


Phone microphone
----------------
PairIt can send your phone microphone to an explicitly selected virtual sink.
It never sends microphone audio to physical speakers.
Create a temporary PulseAudio/PipeWire virtual cable in your user session:
  pactl load-module module-null-sink sink_name=pairit_phone_mic sink_properties=device.description=PairIt_Phone_Mic
Choose PairIt_Phone_Mic under Settings → Phone microphone and enable it.
Choose its monitor input in your calling/recording app, then explicitly start
Microphone in the phone's PairIt Settings. Computer sharing and phone microphone
are mutually exclusive. Disconnect/disable microphone to stop the session.
The command prints a module number; remove the cable with:
  pactl unload-module NUMBER
Never unload a module belonging to another app. If your calling app hides monitor
inputs, configure a virtual microphone source in your audio server first.

Desktop tray
------------
PairIt provides Open PairIt, Settings and Quit in the desktop tray. Keep the
window minimized to continue sharing. Closing the window quits and restores
local audio. The normal taskbar window remains available on desktops without
a tray host; GNOME requires AppIndicator/StatusNotifier support for tray icons.

Shared listening timing
-----------------------
Up to four phones can connect directly or join through a listening invitation.
Phone speakers are valid outputs. A host must already have a live computer
connection before inviting; the guest needs no previous pairing with that computer.
With updated companion and phone apps, allow a few seconds for shared timing
calibration. Each phone uses its measured output latency to target the same
presentation time. OS estimates do not guarantee acoustically identical outputs.
Older phone apps keep their existing timing. Updating all listeners enables the
shared timing feature. A fifth phone receives a clear group-full message.
Phone volume and pause are independent; computer output selection applies to all.

In-app updates (build22 and newer)
---------------------------------
Choose Download & install in the update notice or Settings. PairIt verifies the
signed release, downloads the matching processor/package, then quits and reopens.
Ubuntu/Debian installations request your system password to install the .deb.
Portable installations must be in their own writable folder; their previous
folder is retained for recovery. Pairing/settings stay in your user profile.
Older builds require one manual upgrade to gain this feature.

Optional Bluetooth audio to Android
-----------------------------------
Run /usr/bin/python3 pairit-bluetooth.py from the extracted folder (or /opt/pairit).
This optional helper requires BlueZ, python3-dbus and python3-gi.
Keep PairIt and the helper running. Pair the phone and computer in system Bluetooth
settings. In the Android app, save the computer with the usual QR/link, choose
Bluetooth for that computer and select its bonded device. Ctrl+C stops the helper.
